
# Freelancer Earnings Tracker

A centralized platform for managing, tracking, and analyzing freelance earnings across multiple freelancing platforms and team members.

## Project Overview

Freelancer Earnings Tracker is a multi-user web application designed to help freelancers manage individual earnings while providing a shared view of total team earnings.

The application supports multiple freelancing platforms, weekly earnings records, USD and INR currency tracking, and individual and team-level financial summaries.

## Project Objectives

- Track earnings from multiple freelancing platforms.
- Support multiple users with individual accounts.
- Maintain weekly earnings history.
- Track earnings in USD and INR.
- Calculate individual and combined team earnings.
- Provide a centralized dashboard.
- Maintain secure user authentication.

## Planned Features

- User registration and login.
- Password-based and OTP-based authentication.
- Individual earnings dashboard.
- Team earnings dashboard.
- Freelancing platform management.
- Weekly earnings tracking.
- USD to INR conversion and credited amount tracking.
- Payment history and reports.
- User management.
- About Us page.
